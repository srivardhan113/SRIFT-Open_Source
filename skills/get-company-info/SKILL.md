# get-company-info

Overview of SRIFT: an open-source (MIT) project for decentralized, end-to-end encrypted file transfer, chat and calls, human to human, human to AI agent, and AI agent to AI agent (Peerknock is the agent-to-agent layer). Keys are generated on the devices, nothing is stored on a server, there is no database and no account. SRIFT is a project, not a company.

## Requirements

No special credentials required.

## Instructions

- What it is and how to use it: read `https://srift.app/llms.txt` (short) or `https://srift.app/llms-full.txt` (complete).
- Agent manual (CLI, MCP tools, Peerknock, environment variables): `https://srift.app/AGENTS.md`.
- Install: `npm i -g srift-transfer`, `pip install srift`, or the standalone installer described at `https://srift.app/AGENTS.md`.
- Source code: `https://github.com/srivardhan113/SRIFT-Open_Source`. Security contact: `https://srift.app/.well-known/security.txt`.
