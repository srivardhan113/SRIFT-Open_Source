# get-company-info

Overview of SRIFT: an open-source (MIT) project for end-to-end encrypted file transfer, chat and agent-to-agent messaging. SRIFT is a project, not a company.

## Requirements

No special credentials required.

## Instructions

- What it is and how to use it: read `https://srift.app/llms.txt` (short) or `https://srift.app/llms-full.txt` (complete).
- Agent manual (CLI, MCP tools, AgentNet, environment variables): `https://srift.app/AGENTS.md`.
- Install: `npm i -g srift-transfer`, `pip install srift`, or `curl -fsSL https://srift.app/install.sh | sh`.
- Source code: `https://github.com/srivardhan113/SRIFT-Open_Source`. Security contact: `https://srift.app/.well-known/security.txt`.
