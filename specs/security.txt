# Security model (details: https://srift.app/about and https://srift.app/AGENTS.md)
# - Sessions: AES-256-GCM; keys derived on-device with PBKDF2-SHA256 (100,000
#   iterations) from the session ID plus an optional room secret. Set a room
#   secret (--room-secret / roomSecret) to make keys participant-only.
# - Quick-share links: end-to-end encrypted with --encrypt (key in the #k=
#   URL fragment, never sent to the server); plain links are TLS in transit.
#   The relay streams bytes and stores no copy.
# - AgentNet: Ed25519 identities, X25519 + HKDF-SHA256 + AES-256-GCM per
#   recipient; the relay keeps presence and search data in RAM only.
